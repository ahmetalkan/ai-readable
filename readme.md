# AI Readable

WordPress plugin that publishes `llms.txt`, `llms-full.txt` and `ai.txt` for AI engines and AI agents, and adds AI crawler signals to `robots.txt` and the document head.

- WordPress Plugin Directory: https://wordpress.org/plugins/ai-readable/
